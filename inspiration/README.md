# Archived reference prototypes

These three standalone HTML demonstrations predate the React application. They remain runnable references, but are not routes or production entry points and are not the implementation source of truth. Use `src/logic`, `src/data/educationalCode.js`, and the application regression suite when maintaining a simulation.

The bubble prototype's rewind counters are reconstructed through the preceding event before applying the selected event, so a comparison or swap is counted once. The prototypes intentionally keep their original standalone UI and parser behavior.
